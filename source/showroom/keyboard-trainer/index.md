A touch-typing trainer built for developers. Instead of generic word lists it uses real code snippets and prose from classic texts as training material. Paste any text to practice on your own content.

## Metrics tracked

- Words per minute (WPM)
- Accuracy percentage
- Per-key error heatmap
- Session history stored in `IndexedDB`

## Difficulty modes

| Mode | Description |
|------|-------------|
| Words | Common English words |
| Code | Realistic code snippets |
| Custom | User-pasted text |
