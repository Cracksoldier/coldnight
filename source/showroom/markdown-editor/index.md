A lightweight, keyboard-first Markdown editor that runs entirely in the browser. No account required — drafts are persisted in `localStorage`. The split-pane layout shows raw Markdown on the left and rendered HTML on the right.

## Features

- Syntax highlighting in the editor pane via CodeMirror 6
- Live preview with debounced rendering (50 ms)
- Export to HTML or raw `.md` file
- Dark theme only; no light mode
- ~18 KB gzipped (no framework)
