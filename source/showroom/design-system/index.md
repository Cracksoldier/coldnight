A documentation-first design system built with vanilla CSS custom properties. Ships tokens for color, spacing, typography, and motion — consumed by all other projects in the portfolio.

## Principles

- **Token-driven**: every value is a variable, never hardcoded
- **Dark-first**: designed for dark backgrounds; light mode opt-in
- **Zero runtime**: no JavaScript required for the static component library

## Deliverables

- Figma component library
- SCSS token file exported to CSS custom properties
- Interactive storybook-style HTML docs
