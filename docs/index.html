Features

Everything you need, nothing you don't

14 features, zero runtime dependencies beyond Hexo itself.

🗃️

Responsive post grid

3 → 2 → 1 column responsive grid with cover images, reading-time estimates, and list-view mode.

⭐

Featured post hero

Add pinned: true to any post to promote it to a full-width hero above the grid.

🔁

Related posts

Build-time tag & category scoring surfaces the 3 most relevant posts below each article.

🔍

Full-text search

Instant navbar dropdown. Lazy-fetched, AND-matched, XSS-safe, keyboard-navigable.

🖼️

LightGallery v2

Full-screen image viewer with zoom and thumbnail strip. Auto-mounted or explicit via {% gallery %}.

💻

Code blocks

Language label + one-click copy. Toolbar injected at runtime; line numbers excluded from copy.

📖

Table of contents

Build-time heading list with IntersectionObserver scroll-spy active highlighting.

📊

Reading progress

3px accent bar fixed above the navbar. Passive scroll listener, pointer-events: none.

🔗

Open Graph & SEO

Full og:*, Twitter Card, and canonical tags. Entity-decoded excerpt fallback.

📋

Archive lists

Year-grouped, date-sorted, no pagination. Used by archive, tag, and category pages.

🔌

Tag plugins

{% note %}, {% tabs %}, {% gallery %}, {% download %} — all with full Markdown support.

🏷️

Archive filter chips

Client-side category and tag filter pills on the archive page. Year groups with no matches collapse automatically.

↗

External link indicator

Auto-injects target="_blank" rel="noopener noreferrer" and a subtle ↗ icon on external links in post bodies.

🎨

Design tokens

All colors, spacing, and breakpoints in _variables.scss. Retheme in one file.
